# Система управления бизнесом

### Задача: 

Разработать одностраничное MVP-приложение без микросервисов для управления командой внутри компании.

---
### Технический требования:

- Язык программирования:
  - Python 3.11
- Фреймворк:
  - FastAPI
- ORM:
  - SQLAlchemy + Alembic (миграции)
- Хранение данных:
  - PostgreSQL 16
 
---
### Запуск проекта:

- Клонируйте проект:
  ```python
  git clone https://github.com/annaputilovskaya/BusinessManagementSystem.git
  ```
- Создайте файл .env в корне проекта по образцу (Файл .env.example) и заполните его данными.
  
  Команда для Unix-подобных систем для копирования файла:
  ```python
  cp .env.example .env
  ```
- Убедитесь, что на Вашем устройстве установлен Docker.
  
  Проверка версии Docker:
  ```python
  docker --version
  ```
  Если докер не установлен, [осуществите его установку по инструкции с официального сайта](https://www.docker.com/)
  
- Осуществите сборку образов и запуск контейнеров:
  ```python
  docker compose up -d --build
  ```

### Функционал и бизнес-логика

1. Пользователи (имеют роли администратор, менеджер и обычный пользватель):
   - Самостоятельная регистрация с email и паролем
   - Авторизация / выход
   - Обновление профиля
   - Удаление аккаунта (без восстановления)

![image](https://github.com/user-attachments/assets/6abb2b03-f341-4f81-9e18-df7145582b8b)


2. Команды
   - Создание команды (администратор)
   - Добавление/удаление пользователей в команде (администратор)
   - Просмотр состава команды (все пользователи)
   - Назначение пользователям ролей в команде (администратор)

![image](https://github.com/user-attachments/assets/7d3c7558-4b41-4e9d-be59-bb01f8daa2e9)


3. Задачи
   - Создание задач руководителем (менеджер)
   - Назначение исполнителя (менеджер)
   - Изменеие статуса (исполнитель)
   - Изменение / удаление (менеджер)
   - Комментарии - упрощённый чат внутри задачи (менеджер и исполнитель)
  
![image](https://github.com/user-attachments/assets/58aca9af-2dd0-4f90-b114-91df285c3a56)


4. Оценка работы
   - Руководитель оценивает выполненные задачи: баллы от 1 до 5
   - Пользователь видит свои оценки
   - Вывод средней оценки за период

![image](https://github.com/user-attachments/assets/bf112e0b-986c-4d4e-815e-704ebafb06d0)


5. Встречи
   - Назначение встречи: дата, время, участники (пользователь)
   - Проверка времени, чтобы не накладывались события
   - Список встреч пользователя (участник встречи)
   - Возможность отменить встречу (участник встречи)

![image](https://github.com/user-attachments/assets/a962ab74-f8e0-4bf7-a25c-82dec0e227f5)

   - Отображение задач и встреч за день
